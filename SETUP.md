# Construct Website - Setup Guide

## 🚀 Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Configure Environment Variables**
   ```bash
   cp .env.example .env.local
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

## 📧 Contact Form Integration

The contact form is **already integrated** with Formspree! Just add your form ID:

### Setup Formspree (Recommended - Free tier available)

1. Go to [formspree.io](https://formspree.io) and create an account
2. Create a new form and get your form ID
3. Add to `.env.local`:
   ```env
   NEXT_PUBLIC_FORMSPREE_ID=your_form_id_here
   ```
4. Restart the dev server

**That's it!** The form will now send emails to your configured address.

### Option 2: EmailJS

1. Sign up at [emailjs.com](https://www.emailjs.com/)
2. Install the package: `npm install @emailjs/browser`
3. Update `components/sections/Contact.tsx`:

```typescript
import emailjs from '@emailjs/browser';

// In the onSubmit function:
await emailjs.send(
  'YOUR_SERVICE_ID',
  'YOUR_TEMPLATE_ID',
  {
    fullName: data.fullName,
    email: data.email,
    company: data.company,
    budget: data.budget,
    message: data.message,
  },
  'YOUR_PUBLIC_KEY'
);
```

### Option 3: Custom API Route

Create `app/api/contact/route.ts`:

```typescript
import { NextResponse } from 'next/server';

export async function POST(request: Request) {
  const data = await request.json();
  
  // Add your email sending logic here (Resend, SendGrid, etc.)
  
  return NextResponse.json({ success: true });
}
```

Then update the form to use: `fetch('/api/contact', { ... })`

## 📊 Google Analytics Setup

1. Create a Google Analytics 4 property at [analytics.google.com](https://analytics.google.com/)
2. Get your Measurement ID (format: G-XXXXXXXXXX)
3. Add to `.env.local`:
   ```env
   NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
   ```
4. Restart the dev server

Analytics will automatically track page views and user interactions.

## 🎨 Customization

### Colors
Edit `tailwind.config.ts` to change brand colors:
```typescript
colors: {
  'cta-brass': '#C2A376',  // Your brand color
  'bg-primary': '#0A0A0A',  // Background
  'text-base': '#F5F5F5',   // Text color
}
```

### Fonts
Fonts are configured in `app/layout.tsx`:
- **Serif**: Playfair Display
- **Sans**: Inter
- **Label**: Space Grotesk

## 🚢 Deployment

### Vercel (Recommended)
1. Push code to GitHub
2. Import project on [vercel.com](https://vercel.com)
3. Add environment variables in Vercel dashboard
4. Deploy!

### Environment Variables for Production
Add these in your hosting platform:
```env
NEXT_PUBLIC_FORMSPREE_ID=your_form_id
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
```
